# Whittle public feed

Credential-free release data and public support pages for the Whittle iPhone
app. The private collectors publish only these four app-facing data files:

- `oil-feed.json`
- `history.jsonl`
- `supplier-history.jsonl`
- `electricity.json`

The source repository, collector implementation, status ledgers and
credentials remain private. Each quote or tariff retains its supplier source
URL and collection timestamp. Prices can change between collections; confirm
the current price and terms with the supplier before acting.

prices, terms, or source material beyond rights provided by their respective
owners and applicable law.
